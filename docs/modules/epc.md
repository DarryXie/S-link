# EPC 模块开发需求模板

## 1. 模块目标
- 解决的业务问题：在主框架下生成一个现代化的交互友好EPC前端系统。
- 用户完成任务的核心路径：用户目标是找到具体的配件，并将配件加入购物车中，并通过购物车生成配件订单。通常情况下有三个大致方式：
    1. 通过VIN码查询到具体车型后，在车型下的爆炸图例中找到需要的配件。
    2. 通过品牌-车系-年款-车型的链路找到具体车型，在车型下的爆炸图例中找到需要的配件。
    3. 通过高级查询功能，直接查询配件号或配件名称，找到需要的配件，在配件详情中找到需要的配件。



## 详细功能需求
EPC系统包含首页、EPC查询向导页、左图右数据页、配件详情弹窗、高级查询弹窗。需要**面包屑导航 (Breadcrumbs)**，记录当前层级路径（如：EPC首页 > 五菱 > 宏光MINI > 动力总成 > ...），点击面包屑可实现快速向上跳转。

### 1. EPC首页
* **多功能查询框**：位于页面中央，用户可以输入VIN码、配件号、配件名称，也可以直接复制VIN码图片进行OCR得到VIN信息。
* **车型信息弹窗**：默认隐藏，显示时以卡片弹窗形式在页面中央弹出。当用户输入的内容为VIN码时弹出（demo演示时输入17位内容）。内容包含：单独一行的title（“品牌 / 车系 / 年款 / 车型”），以表格形式显示的其他车型信息（完整VIN码、车辆类型、能源形式、排放标准、车身结构、生产国家、生产日期）。“前往EPC”按钮，点击后进入EPC查询向导页开始具体的VIN码直达流程。
* **品牌矩阵**：搜索框下方横向排列汽车品牌卡片（品牌Logo + 名称）。模拟数据使用：“五菱”、“宝骏”、“新宝骏”。点击具体品牌后，进入该品牌的车型选择页，开始对应的车型正向选车流。
* **历史记录**：在页面右侧竖直放置，显示每次在EPC中工作的最后停留位置。卡片列表形式，可滚动。当用户从EPC工作中返回系统首页后，就记录该次工作的最后停留位置，点击卡片回到当时的工作内容。

### 2. EPC查询向导页 (目录树层级)
* **正向选车流**：点击“品牌”进入后，展示该品牌下的“车系”（图片+名称）-> 用户点击车系选择“年款” -> 选择具体“车型配置” -> 最终进入该车型的“主分组”。
* **VIN码直达流**：如果是通过VIN码匹配，跳过选车步骤，直接展示该车辆对应的“主分组”。
* **分组递进**：主分组（如：发动机） -> 子分组（如：润滑系统） -> 右侧显示爆炸图例列表 -> 点击特定图例进入“左图右数据页”。


### 3 爆炸图例用法列表页 (左图右数据页)
核心工作台页面。
* **左侧爆炸图区 (Interactive Diagram)**：显示配件分解图。支持鼠标滚轮缩放、拖拽平移。图上有热点(Hotspots)标定。点击图上某个配件热点时，右侧表格中对应的数据行自动高亮并滚动到可视区域。
* **右侧数据列表区 (Data Table)**：
    * *表头字段*：热点号、配件号、配件名称、备注、单车用量、最小包装数、币种、价格、操作列（加入购物车）。
    * *双向联动*：点击列表中的某一行，左侧爆炸图中的对应热点自动高亮放大。
    * *交互*：点击“配件号”可打开弹窗查看“配件详情”。
    * *加购逻辑*：点击行末的“加入购物车”按钮，弹出数量步进器（默认值为：最大值 [最小包装数, 用量]）。确认后，将配件与当前车型/VIN码绑定加入购物车，**同时更新顶部导航栏上的购物车角标数量**。如果点击关闭按钮，则收起弹出数量步进器。


### 4 配件详情弹窗/侧滑窗
* **基本信息**：配件图片（支持多图轮播）、配件号、名称、最小包装数、币种、单价、备注描述。
* **操作区**：加入购物车按钮。
* **配件适用性 (Applicability)**：列表展示该配件还可以装配在哪些其他车型上，包含车型代码、车型名称、品牌。
* **替换关系 (Supersession)**：展示该配件的生命周期替换链（如：A被B替换，B被C替换的层级关系）。


### 5 高级查询弹窗
* **条件查询区**：通过输入的不同条件，联合查询。可输入内容有：VIN、车型（下拉级联选择：品牌-车系-年款-车型）、图例分组（下拉级联选择：一级分组-二级分组）、图例编号、图例名称、零件编号、零件名称。点击查询按钮后开始查询，点击重置按钮情况查询条件。
* **查询结果区**：通过页签显示查询到的不同种类的内容，如下：   
    * 1. “匹配零件”页签：符合条件的配件。内容：配件缩略图、配件号、是否有替换件icon、配件名称、最小包装数、币种、价格、加入购物车按钮。点击配件号在配件详情弹窗中显示该配件的详情信息
    * 2. “匹配图例”页签：符合条件的配件。内容：图例缩略图、图例号、图例名称、图例所在车型（品牌-车系-年款-车型）、图例所在分组（一级分组-二级分组）。点击内容后在爆炸图例用法列表页中显示该车型下这种图例的内容。
