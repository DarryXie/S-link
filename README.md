# S-Link

面向汽车主机厂后市场买方用户的前端工作台原型，首期覆盖主系统框架、Dashboard、EPC 占位页、配件订购占位页、AI 智能助手抽屉、购物车抽屉、多语言切换与主题色切换。

## 启动方式

```bash
npm install
npm run dev
```

## 当前目录结构

- `src/modules/layout`：主系统框架、导航、全局面板
- `src/modules/dashboard`：系统首页
- `src/modules/epc`：EPC 占位页
- `src/modules/orders`：配件订购占位页
- `src/modules/assistant`：AI 智能助手抽屉
- `src/modules/cart`：购物车抽屉
- `docs/modules`：各模块后续细化用的需求模板
